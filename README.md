# Customer-Churn
Telco Customer Churn Analysis & Customer Retention Strategy

Project Overview

This project focuses on analysing customer churn in a telecommunications company to understand customer behavior, identify high-risk segments, and develop data-driven customer retention strategies.

The analysis was performed using Python, MySQL, and Power BI.

Business Problem

Customer churn directly impacts business revenue and long-term customer relationships.

The objective of this project is to:

- Understand overall customer churn patterns.
- Identify customer segments with high churn rates.
- Analyse the impact of contracts, internet services, and payment methods.
- Understand customer behavior and tenure.
- Recommend strategies to improve customer retention.

Tools & Technologies

- Python
- Pandas
- Jupyter Notebook
- MySQL
- SQL

Project Workflow

1. Data Exploration and Cleaning using Python.
2. Missing value identification and data type correction.
3. Data loading and SQL analysis using MySQL.
4. Customer segmentation and churn analysis.
5. Interactive dashboard development using Power BI.
6. Business insights and retention recommendations.

Key Business Metrics

Metric| Result
Total Customers| 7,043
Churned Customers| 1,869
Overall Churn Rate| 26.54%
Retention Rate| 73.46%

Key Business Insights

1. Contract Analysis

Month-to-month customers have a significantly higher churn rate than one-year and two-year contract customers.

2. Internet Service Analysis

Fiber Optic customers show higher churn compared to DSL and customers without internet service.

3. Payment Method Analysis

Electronic Check users have the highest churn rate among payment methods.

4. Customer Tenure Analysis

Customers with shorter tenure are more likely to churn. The largest number of churned customers belongs to the 0–12 month tenure group.

5. Customer Behavior Analysis

Senior Citizen customers show a higher churn rate than non-senior customers.

6. High-Risk Customer Segmentation

The Month-to-month + Fiber Optic + Electronic Check segment has a churn rate of approximately 60.37%.

Business Recommendations

- Encourage customers to switch to long-term contracts through loyalty offers.
- Introduce targeted retention campaigns for high-risk segments.
- Improve onboarding and customer engagement during the first year.
- Investigate Fiber Optic service quality and customer complaints.
- Promote automatic payment methods and improve billing convenience.

Limitations & Future Scope

- Investigate the reasons behind missing TotalCharges values and document the treatment.

Conclusion

This project demonstrates how Python, SQL, and Power BI can be used together to transform raw customer data into meaningful business insights and actionable customer retention recommendations.

The analysis highlights customer segments that require greater attention and provides a foundation for data-driven retention strategies.
